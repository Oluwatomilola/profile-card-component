# Profile Card Component

A responsive, accessible profile card component built with vanilla HTML, CSS, and JavaScript.

## Features

- Responsive design
- Accessible markup
- Interactive elements
- Test-ready with data-testid attributes

## Development

1. Open `index.html` in your browser
2. Or use live server: `npm run dev`

## Testing

All elements include `data-testid` attributes for automated testing.

## Browser Support

- Chrome 60+
- Firefox 55+
- Safari 12+
- Edge 79+
